# Pagos y recargas (M11)

La única pasarela activa es `PAGOS_PASARELA=simulada`. El cobro de prueba no mueve dinero real. La URL del simulador se construye con `PAGOS_SIMULADOR_BASE_URL`. Configure `PAGOS_WEBHOOK_SECRET` con un secreto propio antes de exponer el endpoint. La confirmación del navegador nunca acredita saldo: el webhook firmado se contrasta con `consultar()` y el mismo proceso se puede recuperar por reconsulta.

La API de cliente vive provisionalmente en `/api/v1/recargas/ordenes/`; M12 trasladará el ruteo a `mi.subepe.app`. `ClienteCuenta` es el enlace mínimo usuario–cuenta y se sustituirá o ampliará durante M12. Se requiere sesión de cliente y CSRF en POST. El esquema de estas rutas está en `docs/contratos/api-cliente-v1.yaml`.

La recarga pagada queda acreditada en la cuenta y pendiente de aplicación a la tarjeta. El reembolso automático está bloqueado incluso si `aplicada_en` sigue vacío: la recarga pudo haberse distribuido por `sync` o `sync/v2` a un validador desconectado, que aún podría escribirla en la tarjeta. Se rechaza antes de pedir el reembolso a la pasarela o de revertir M10. La corrección requiere un protocolo de cancelación con confirmación fiable de todos los validadores que pudieron recibir la recarga, o un procedimiento manual que compruebe y resuelva la deuda antes de devolver dinero. Una pasarela real también debe confirmar el reembolso antes del reverso y permitir recuperación ante fallos de red. No se habilita sustituyendo solo `PAGOS_PASARELA`.

Programar en la VM, tras el despliegue y validación operativa, `python manage.py revisar_ordenes` cada minuto y `python manage.py conciliar_pagos --dia AAAA-MM-DD` una vez al día. El PDF propone cada 5 minutos, pero con el umbral de reconsulta de 2 minutos eso podría tardar hasta 7 minutos desde la creación; cada minuto permite recuperar un webhook perdido antes de 5 minutos. El comando diario usa ayer si se omite `--dia`. Ambos devuelven error ante incidencias; la conciliación crea alertas. Aún no hay tareas configuradas en producción.
