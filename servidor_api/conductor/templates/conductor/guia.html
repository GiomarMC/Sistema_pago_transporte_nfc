Sincronizar el bus

  1. Abre subepe.app/conductor/ en Chrome para Android e inicia sesión. Activa Bluetooth y datos móviles.
  2. Acércate al validador y pulsa Conectar validador. Elige SubePe-V… con el número de tu bus.
  3. Comprueba el número de pendientes. Mantén el celular cerca hasta ver el resumen de viajes subidos.
  4. Si no tienes datos, los paquetes quedan guardados. Abre la página cuando recuperes datos. No borres los datos del navegador.

Si algo falla

SituaciónQué hacer
No aparece el busAcércate, comprueba que esté encendido y desconecta otro celular.
Conexión cortadaVuelve a pulsar Conectar validador.
Paquetes guardadosConserva este navegador y vuelve a abrir la página con datos móviles.
Servidor rechaza paquetesAvisa al responsable de operaciones. No borres la cola.

Los viajes repetidos no se cobran dos veces. Los acuses vuelven al bus en la siguiente sincronización.
